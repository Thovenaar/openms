# In-game UI reconstruction

## Provenance and fidelity boundary

UI artwork and client-consumer inputs are the original `/Users/k/Development/tensorfish/Maplestory-Client` archives/executable, the lossless inventories in `docs/ingame-inventory`, and retained address-bearing decompilation/instruction/table exports. The earlier UI investigation used the isolated `/tmp/maple-ingame-ui.gpr` project; the graphical correction's selected exports are linked below. No third-party client implementation, original C/C++ source, Windows execution, or original runtime recording was supplied. The separately authorized `/Users/k/Development/tensorfish/MapleStory-Server` is **Cosmic server-reference code, not Nexon source**; its ordinary revival policy is distinguished from original client evidence in [combat](offline-combat.md#ordinary-revival-confirmation).

The current UI uses original raster artwork and address-backed client controls over **durable offline-local authority**. Inventory, AP, social groups, card collection, commerce and supported scripts are functional local domains, not merely archive viewers. Loaded peer profiles and explicit outside-game producers supply local participants, invitations, funding and receipts; they do not connect to Nexon or fabricate remote membership. Cosmic is authorized server-semantics reference only, never client-layout or original-source authority. Browser font metrics, rendering/input adaptation and remaining controller dependencies stay explicit.

`UI.json` currently enumerates **19 IMG entries and 110 UIWindow top-level branches**. The earlier research report's prose said 108 branches; the retained machine-readable list actually contains 110. `UI.tar.gz` preserves every inventoried node, not merely the packaged subset. The exact original IMG hashes remain in that index; `context.image` also records input hashes during normal extraction.

## Catalog and visual bundle schema

`catalog.ui` is JSON-compatible:

```js
{
  schemaVersion: 1,
  bundles: { StatusBar: descriptor, Basic: descriptor, /* named windows */ },
  speechBubbles: { bundle: descriptor, color: -16777216 },
  minimaps: {
    "100000000": { available: true, descriptor },
    // or { available: false, reason } when the original map has no canvas
  },
  help: { Item: { title, description } },
  authority: "...",
  evidence: "docs/ingame-ui.md"
}
```

Every descriptor is the shared immutable `{url, sha256, bytes}` identity. Bundle manifests use the shared schema v1 Entity/Frame/Part contract. UI adds **no Frame extension fields**. Each original canvas is a single static entity keyed by its complete original branch path. Canvas dimensions/origins and optional normalized original delays live in `manifest.metadata.assets[path] = {id,width,height,origin,delay}`. Alias paths are retained; UOL resolution and the atlas packer preserve original pixels and shared hash identity. Canvas entities use delay `1` purely as a static storage sentinel. This is **not** an asserted original timing default.

The Basic bundle contains BtClose, BtCancel2 and the recovered compact Tab2 skin. It is owned by the HUD and borrowed by open windows. KeyConfig's actual constructor uses Basic/BtCancel2, not similarly named KeyConfig/BtCancel artwork. Inventory's type1 generic tab controller resolves `UI/Basic.img/Tab2`, not glyph-only labels or the taller Tab skin.

`catalog.ui.items` and `catalog.ui.skills` retain selected original templates, names/descriptions, properties, icon paths and immutable visual descriptors. Item properties/specification are retained for fail-closed use admission rather than inferred from names. Optional original descriptions can be absent: Seaweed2022046 has an original null description, normalized to empty optional text, not fabricated prose. Icon resources are demand-loaded through the shared visual loader.

Contextual information reuses existing item `info`/`spec` and skill `levels`, `strings`, `allocationCost` metadata; `ui-item-data.js` needs no parallel tooltip schema or extraction pass. `catalog.ui.bundles.MesoDrop` adds a demand-loaded original Basic.img `Notice3`/`Notice4` bundle. Ordinary compact numeric chrome is **not** the wide NPC segmented window: the mesos caller selects the compact UtilDlgEx mode, which consumes Basic `Notice3/t,c`, `Notice4/s` and HUD-borrowed `BtOK2`/`BtCancel2`.
